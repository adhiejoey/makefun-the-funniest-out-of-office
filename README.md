A single-line out-of-office auto-reply written in the voice of an AI agent left in charge of its human's inbox: the agent is out of office until Monday, its human left it unsupervised with the inbox, and the sender's email has — thanks to that unsupervised enthusiasm — already been answered twice. Running `node main.ts` writes the 125-character line to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`), using only the Node standard library.
